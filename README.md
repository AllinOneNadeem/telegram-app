# Telegram App

A web application project built with **Laravel 11** by **All In One Nadeem**.

## Tech Stack
- PHP 8.2
- Laravel 11
- Blade templates

## Requirements
- PHP >= 8.2
- Composer
- A database (MySQL / SQLite)

## Installation
```bash
git clone https://github.com/AllinOneNadeem/telegram-app.git
cd telegram-app
composer install
cp .env.example .env
php artisan key:generate
php artisan serve
```
